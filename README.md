# Start Here

This repository is the entry point to my public work. I am a principal-level software engineer focused on decision architecture: the structural design of how systems and organisations make decisions, and the architectural causes of delivery success and failure.

Most of what follows is local-first, correctness-first and built to run on real machines rather than sit behind a login. Many of the desktop applications are packaged for Windows, macOS and Linux. The projects below are ordered by how directly they reflect how I design and build, strongest first.

## Decision Architecture

The core of my work: a thesis on the structural design of decision-making, together with the software and instruments that make it executable.

- **[Fulcrum](https://oernster.github.io/fulcrum/):** The Decision Architecture model made executable. A chess-like board that scores organisational structure and valuates every move, from blunder to great.
- **[LatencyLab](https://oernster.github.io/latencylab/):** A design-time latency simulator for event-driven systems. Deterministic and seeded, it prices the cost of structure before the structure hardens.
- **[crankthecode.com](https://www.crankthecode.com):** The Decision Architecture thesis in long form: how the structure of decisions governs whether systems and organisations succeed or fail.
- **[Decision Architecture series](https://www.amazon.co.uk/Decision-Architecture-Foundations-Patterns-Relativistic/dp/B0GTMVV8T5/):** Four books covering the foundations, patterns, move space and relativistic systems of organisational decision-making.

## Protocol and standards

- **[MMSP Specification](https://oernster.github.io/MMSP-Spec/):** A draft IETF specification for a multimedia evolution of RSS, with JSON Schema validators and a conformance suite mirroring the spec.
- **[Meridian](https://oernster.github.io/meridian/):** A local-first feed client for MMSP, RSS and Atom; the reference implementation of the protocol above.

## Applications

Shipped desktop and web applications, most packaged for multiple operating systems.

- **[PigeonPost](https://www.pigeonpost.ink/):** A calm, local-first email, calendar and contacts client for Windows, macOS and Linux.
- **[NarrateX](https://www.narratex.co.uk):** Converts written content into structured, listenable audio.
- **[ClearBudget](https://oernster.github.io/ClearBudget/):** A personal budgeting and solvency tool for income, bills and credit cards, with detailed forecasting.
- **[Calendifier](https://oernster.github.io/Calendifier/):** A calendar, events and notes application with full internationalisation.
- **[Trainer](https://oernster.github.io/Trainer/):** Aggregates train times, weather and astronomy data into a single desktop view.
- **[FancyClock](https://oernster.github.io/FancyClock/):** A timezone-aware world clock with skins and internationalisation.
- **[AudioDeck](https://oernster.github.io/AudioDeck/):** Stream Deck audio-device switching for Windows.
- **[Stellody](https://www.stellody.com):** Music discovery over your local library, surfacing genre-related top tracks via MusicBrainz.

## Libraries and developer tooling

- **[AxisDB](https://pypi.org/project/axisdb/):** A tiny embedded document database for Python, addressing JSON documents by N-dimensional coordinate keys. Published to PyPI: `pip install axisdb`.
- **[Locus](https://oernster.github.io/locus/):** A native Windows task board that mirrors coding-agent tool calls onto a live board in real time.
- **[CommandFixer](https://oernster.github.io/CommandFixer/):** PowerShell command autocorrect for mistyped commands.
- **[Coin Analysis](https://oernster.github.io/coin-analysis/):** A numismatic coin analyser using a hybrid of OCR and a scikit-learn classifier.

## What to look for

- Decision boundaries and where authority sits
- System boundaries and the interfaces between them
- Architectural intent: clean layering, local-first storage and correctness ahead of premature optimisation
